# Тестовое задание ТОЛЬКООПТ

## Части 1–2. Вопросы и архитектура

Для проверки достаточно краткой версии. Развёрнутую вынесла в отдельный файл, чтобы уложить основной ответ в одну страницу и сохранить аргументацию для обсуждения решения на встрече.

- [Краткая версия для проверки](<Тестовое задание ТОЛЬКООПТ — части 1 и 2.docx>) содержит пять вопросов, пояснения к двум приоритетным, допущения и архитектуру почасового обновления прайсов.
- [Развёрнутая версия для обсуждения](<Развёрнутая версия — части 1 и 2.docx>) объясняет, как ответы на вопросы влияют на проектирование, и подробнее описывает поведение системы при сбое площадки, повторном импорте и откате пилота.

## Часть 3. Расчёт рекомендуемой цены

В [starter.py](starter.py) находится исправленная функция `recommend_price` и пример запуска. В [test_starter.py](test_starter.py) три теста. Они проверяют расчёт с фильтрацией и округлением вниз, сохранение текущей цены при неполном ответе источника и обработку ответа, пришедшего после тайм-аута.

Для запуска нужен Python 3.10 или новее. Достаточно стандартной библиотеки.

```bash
python3 starter.py
python3 -m unittest -v test_starter
```

Ожидаемый результат примера — `Decimal('4728.00')` и решение `APPLY`.
