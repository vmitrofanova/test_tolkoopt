## Часть 3. Расчёт рекомендуемой цены

В [starter.py](starter.py) находится исправленная функция `recommend_price` и пример запуска. В [test_starter.py](test_starter.py) три теста. Они проверяют расчёт с фильтрацией и округлением вниз, сохранение текущей цены при неполном ответе источника и обработку ответа, пришедшего после тайм-аута.

Для запуска нужен Python 3.10 или новее. Достаточно стандартной библиотеки.

```bash
python3 starter.py
python3 -m unittest -v test_starter
```

Ожидаемый результат примера — `Decimal('4728.00')` и решение `APPLY`.
